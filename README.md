# Калькулятор целых чисел (Console Calculator)

Консольная утилита для выполнения базовых арифметических операций над 64-битными целыми числами. Поддерживает сложение, вычитание, умножение, деление, возведение в степень и вычисление факториала с контролем переполнения.

## Назначение

Проект предназначен для демонстрации надежных вычислений на C++ без использования сторонних библиотек. Основная задача — корректная обработка граничных случаев (переполнение типа `long long`, деление на ноль) и предоставление понятной диагностики ошибок через стандартный вывод.

## Возможности

- **Арифметика:** `+`, `-`, `*`, `/`
- **Специальные операции:**
  - `^` — возведение в степень (только неотрицательные показатели)
  - `!` — факториал (только неотрицательные числа)
- **Безопасность:**
  - Проверка переполнения через встроенные функции компилятора (`__builtin_*_overflow`)
  - Обработка деления на ноль и случая `LLONG_MIN / -1`
  - Валидация входных данных

## Требования

- **Компилятор:** GCC или Clang (с поддержкой builtins)
- **Стандарт C++:** C++17 или выше
- **Система сборки:** CMake 3.16+
- **ОС:** Linux / macOS / Windows (WSL)

## Сборка

Для конфигурации и сборки проекта выполните следующие команды в корневой директории:

```bash
cmake -S . -B build
cmake --build build
```

Исполняемый файл появится по пути: `build/calculator`

## Использование

Программа принимает ровно три аргумента командной строки:

```bash
./build/calculator <число1> <операция> <число2>
```

| Аргумент | Описание |
| :--- | :--- |
| `<число1>` | Первый операнд (целое число, тип `long long`) |
| `<операция>` | Символ операции: `+`, `-`, `*`, `/`, `^`, `!` |
| `<число2>` | Второй операнд (для унарных операций `!` может быть любым, но должен присутствовать) |

## Примеры

Ниже приведены реальные примеры запусков и вывода программы:

| Команда | Вывод программы | Описание |
| :--- | :--- | :--- |
| `./build/calculator 15 + 25` | `15 + 25 = 40` | Успешное сложение |
| `./build/calculator 2 ^ 10` | `2 ^ 10 = 1024` | Возведение в степень |
| `./build/calculator 6 ! 0` | `6! = 720` | Вычисление факториала |
| `./build/calculator 100 / 0` | `Error! Division by zero!` | Деление на ноль |
| `./build/calculator 9223372036854775807 + 1` | `Error! Overflow!` | Переполнение результата |
| `./build/calculator -5 ! 0` | `Error! Factorial of a negative number is undefined!` | Отрицательный факториал |
| `./build/calculator 10 % 5` | `Error! Unknown operation!` | Неподдерживаемый оператор |
| `./build/calculator 10 +` | `Error! Usage: <num1> <op> <num2>` | Недостаточно аргументов |

## Архитектура

Приложение построено по принципу конвейера обработки данных:
**Ввод (аргументы) -> Парсинг -> Вычисление -> Вывод**.

### Логические блоки

1.  **Парсинг (`parse`, `parseNumber`)**
    Отвечает за преобразование строковых аргументов `argv` во внутренние типы данных. Использует `std::stoll` с обработкой исключений для валидации чисел.
2.  **Вычисление (`calculate`)**
    Диспетчеризатор, который на основе символа операции вызывает соответствующую математическую функцию.
3.  **Математические операции**
    Реализованы в виде отдельных функций, возвращающих статус `Status`. Результат передается через выходной параметр `long long& out`.
    -   `Status addition(long long a, long long b, long long& out)`
    -   `Status subtraction(long long a, long long b, long long& out)`
    -   `Status multiplication(long long a, long long b, long long& out)`
    -   `Status division(long long a, long long b, long long& out)`
    -   `Status power(long long a, long long b, long long& out)`
    -   `Status factorial(long long n, long long& out)`
4.  **Вывод (`output`)**
    Формирует человеко-читаемое сообщение на основе структуры `Task` и кода статуса.

### Основные типы данных

-   **`enum class Status`**: Перечисление кодов завершения операций.
    -   `Ok`: Успешное выполнение.
    -   `Overflow`: Выход результата за пределы `long long`.
    -   `DivisionByZero`: Попытка деления на ноль.
    -   `NegativeExponent`: Отрицательный показатель степени.
    -   `NegativeFactorial`: Отрицательное число для факториала.
    -   `InvalidNumber`: Ошибка парсинга аргумента.
    -   `UnknownOperation`: Неизвестный символ операции.
    -   `BadArgumentCount`: Неверное количество аргументов CLI.
-   **`struct Task`**: Контекст задачи, хранящий операнды (`value1`, `value2`), операцию (`operation`), текущий статус (`status`) и результат (`result`).

## Обработка ошибок

Все ошибки классифицированы и имеют уникальные сообщения:

| Статус | Причина | Сообщение пользователю |
| :--- | :--- | :--- |
| `DivisionByZero` | Делитель равен 0 | `Error! Division by zero!` |
| `Overflow` | Результат не помещается в `long long` | `Error! Overflow!` |
| `NegativeExponent` | Показатель степени < 0 | `Error! Negative exponent is not supported!` |
| `NegativeFactorial` | Аргумент факториала < 0 | `Error! Factorial of a negative number is undefined!` |
| `InvalidNumber` | Аргумент не является числом | `Error! Invalid number!` |
| `UnknownOperation` | Оператор не из списка поддерживаемых | `Error! Unknown operation!` |
| `BadArgumentCount` | Аргументов меньше или больше 3-х | `Error! Usage: <num1> <op> <num2>` |

## Ограничения

1.  **Тип данных:** Все вычисления производятся в типе `long long` (знаковое 64-битное целое). Диапазон: от `-9 223 372 036 854 775 808` до `9 223 372 036 854 775 807`.
2.  **Отсутствие дробных чисел:** Операции с плавающей точкой (`double`, `float`) не поддерживаются.
3.  **Синтаксис унарных операций:** Для операции факториала (`!`) требуется передавать третий аргумент-заглушку (например, `5 ! 0`), так как парсер ожидает строго 3 аргумента.
4.  **Зависимость от компилятора:** Используются специфичные для GCC/Clang функции `__builtin_add_overflow` и аналоги. При смене компилятора может потребоваться адаптация блока проверок переполнения.
